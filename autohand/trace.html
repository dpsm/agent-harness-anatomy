      Loop map

      One pass — steering drain → prompt assembly → tool filter → model call → parse → repair guards → blacklist-first permission check → batched execution → results appended → memory extraction. Steering joins only at iteration boundaries, never between a tool call and its result.
      Bounded, not event-driven — a plain for loop in ReactLoopRunner: 100 iterations by default, 1,000 while executing an accepted plan. The model finishes by answering with no tool calls; exhausting the cap is soft — one summary call, then {status: 'incomplete'}. Run budgets exist but are opt-in.
      Two protocols, one loop — native providers get function schemas; the rest get no schemas and must answer in a text protocol parsed by ReactionParser. Much of the repair apparatus — loop guard, reflection guard, deferred-action classifier, truncation recovery — exists to keep that second protocol honest.
