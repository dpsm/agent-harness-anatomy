Top-down dissections of agent harnesses that run on milliwatts. Same discipline as the main series — pinned source, every claim verifiable — adapted for event-driven systems under physical constraints: power budgets, KB-scale memory, no guaranteed connectivity.

E1 — ESP-Claw: the agent loop that waits for an invitation

A reactive embedded system first and an agent second. Every input — an instant message, a schedule tick, a boot event — lands on an event bus; router rules decide what happens next, and the fast paths complete in milliseconds with no LLM involved. The LLM is cloud-only, safety is architectural rather than gated, and Lua is not sandboxed. Espressif's reference design for agents on the ESP32.
